# Healthcare Patient Insight Dashboard
## Project Overview
A comprehensive data analytics project designed to uncover meaningful insights from healthcare patient records. 
This dashboard visualizes key metrics such as patient visits, cholesterol levels, blood pressure patterns and medication usage, highlighting high‑risk groups, missing data patterns and condition‑based trends to support data‑driven decision‑making.

## Dataset Description and Privacy Note 
The dataset is made up of patient visit records obtained from a publicly available GitHub repository. It includes demographic fields such as age and gender, clinical measurements like cholesterol levels and blood pressure, as well as indicators for various conditions including asthma, diabetes, and hypertension. The data intentionally contains inconsistencies, missing entries, and formatting problems, making it a realistic example for practicing data cleaning, transformation, and visualization workflows.

Although the dataset includes patient names, these are clearly synthetic placeholders commonly used in demo datasets. They do not correspond to real individuals, and no personally identifiable or sensitive information is present. The data is fully anonymized, non‑sensitive, and intended solely for educational and analytical use, ensuring compliance with privacy standards.
